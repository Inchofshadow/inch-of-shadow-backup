  [ ] Submit to Symphonic — minimum 8 weeks out for Beatport processing
  [ ] Send advance promos to promo list (30-50 DJs) — private SoundCloud link, password protected
  [ ] Begin media outreach: pitch premieres to top 5-10 blogs/channels

## 2. Platform Strictness Ratings

```
STRICTNESS SCALE:
  [HARD BLOCK] = Total failure for that release. No recovery.
  [SEVERE]     = Significant damage. Hard to recover within release window.
  [MODERATE]   = Reduced impact, recoverable with effort.
  [LOW]        = Suboptimal but not damaging. Easy to fix.
  [FLEXIBLE]   = Platform is forgiving.
```

| Platform | Rule | Strictness | Recoverable? |
|----------|------|-----------|-------------|
| Spotify | Pitch editorial before release | **HARD BLOCK** | No — form closes permanently when track goes live |
| Spotify | Submit 7+ days before release | **SEVERE** | Partial — Release Radar may miss launch week |
| Spotify | Submit 28+ days before release | **MODERATE** | Yes — but editorial chance smaller |
| Beatport | Deliver 3+ weeks before release | **HARD BLOCK** | No — auto-ineligible for editorial features |
| Beatport | Pre-order 28 days before | **SEVERE** | No — pre-order window can't be added retroactively |
| Instagram | Respond to comments within 1 hour | **MODERATE** | Partial — next post starts fresh |
| Instagram | No TikTok watermarks on Reels | **SEVERE** | No for that video — delete and repost clean |
| SoundCloud | Engagement in first 24-48 hours | **SEVERE** | Only via repost campaigns |
| SoundCloud | Wrong/empty tags at upload | **MODERATE** | Yes — but initial test already happened with wrong audience |
| Bandcamp | Wrong genre in Discover tree | **MODERATE** | Yes — edit tags anytime |
| Bandcamp | Pre-order without streaming track | **MODERATE** | Yes — add streaming track immediately |
| YouTube | No custom thumbnail | **MODERATE** | Yes, upload anytime (needs advanced features) |
| YouTube | Bad title format | **LOW** | Yes — edit anytime |

**The two rules worth treating as sacred:**
1. **Pitch Spotify editorial BEFORE release.** Everything else has workarounds. This does not.
2. **Deliver to Beatport 3 weeks minimum.** Ineligibility for editorial is permanent for that release.

## 3. Spotify

### Profile Optimization (One-Time Setup, Refresh Each Release)
- Claim via artists.spotify.com immediately
- **Bio:** Genre + location + sound + influences. Include these terms: your genre names, location ("Berlin"), similar artist references. This bio is indexed externally and feeds Spotify's NLP categorization.
  - Example: "Berlin-based electronic producer making dark disco, acid, EBM, and cinematic techno. Influenced by Dark Entries, Clone, L.I.E.S."
- **Photos:** Profile image 690x500px minimum. No logos, no text overlays, clean background. Update each release cycle.
- **Artist Pick:** Always pin your latest release or best-performing track
- **Canvas:** Add 3-8 second looping video to every track. Tracks with Canvas see up to 145% more shares and 20% more saves.
- **Create a public playlist** with your tracks + similar artists. Title it with searchable keywords (e.g., "Dark Disco Berlin Underground"). This helps Spotify's algorithm categorize you.
- **Link social accounts** in profile settings

### Metadata — Set Correctly via Symphonic Before Upload
Spotify uses metadata + audio analysis + NLP (web crawls) to categorize and recommend tracks.
- **Genre:** Select primary genre and all available subgenres. Mismatch = wrong editor sees your pitch.
- **Mood tags:** melancholic, dark, hypnotic, driving — whatever fits
- **BPM:** accurate
- **Language:** set correctly even for instrumentals
- **ISRC codes:** unique per track
- **Track title:** standard format only. No keyword stuffing. No "Song Name [dark disco hypnotic techno vibes]"

### Editorial Pitch — The Full Process
Spotify editorial pitch is the most important single action before any release.

**Eligibility:** Track must be unreleased. Pitch via Spotify for Artists > Music > Upcoming > Pitch a Song. Option disappears the moment the track goes live — permanently.

**Submit 28 days before release.** Spotify's official minimum is 7 days but industry practitioners confirm this is insufficient for independent artists without PR support. At 7 days your Release Radar triggers but editorial review is unlikely to happen in time.

**What happens at each timing:**
- 28+ days: editorial team has time to review, categorize, schedule. Pre-save traction accumulates as a signal. Best chance.
- 14-21 days: reviewed but higher risk of "considered but not scheduled."
- 7 days: Release Radar triggers for followers but editorial review unlikely.
- Less than 7 days: Release Radar may miss launch week. Pushed to next Friday cycle.
- After release: pitch form gone. No recovery for that track.

**The 500-character pitch — what to include:**
- Genre + mood + BPM
- Story behind the track
- Target listener/scenario ("perfect for a late night Berlin DJ set")
- Specific Spotify playlists where it fits
- Any promo planned (premiere, DJ support, press)
- Your location (editors look for regional music)
- Mention promotion plans

**Pitch template:**
```
Dark disco meets acid, recorded in Berlin, 120 BPM. Hypnotic, driving, built 
for late nights. Influences: Dark Entries, Clone, L.I.E.S. Fits: "Berlin 
Calling", "Dark Disco", "Underground Electronic". Premiere secured on [blog]. 
Promo sent to 30+ DJs in dark disco/acid scene. First release in 2026 
singles campaign. Berlin-based independent producer, mixer, mastering engineer.
```

**Update your pitch if press comes in after submission.** You can edit up to the day before release.

**Pitching every release can hurt you.** Editors track your history. If you pitch frequently with low engagement results, it signals poor traction. Only pitch your strongest track.

### Algorithm Signals — Priority Order
1. **Save rate** — THE most important. Target 20%+ excellent. 10%+ solid for new artist.
2. **Repeat plays** — stream-to-listener ratio above 1.5 is healthy
3. **Completion rate** — first 20-30 seconds determine if people skip. Hook early.
4. **Skip rate** — high skip rate = algorithm deprioritizes
5. **Playlist adds** — user-generated playlists adding your track
6. **Follower growth** — around release
7. **External traffic** — NEW IN 2026: links from social media and blogs pointing to Spotify are now an explicit algorithmic quality signal. Cross-platform promotion is technically advantageous, not just strategically.

**Heuristic for Discover Weekly:** approximately 2,500 streams + 250 saves in first 1-3 weeks (informal industry estimate, not confirmed by Spotify).

**In 2026 the algorithm weights save rate and repeat-listen ratio roughly 3x higher than raw stream volume** when deciding what to push into Discover Weekly and Release Radar (Chartlex, 2026 data from 1,200+ campaigns).

**Tell fans explicitly:** "Save this track on Spotify" not just "stream it." Saves feed the algorithm directly.

### Release Radar
- Updates every Friday
- Your followers automatically get your new release in their Release Radar if you pitch 7+ days before
- Without pitching: Spotify picks which track from your release to include — you lose control
- With pitching: your focus track goes to all followers
- Tracks can appear in Release Radar for up to 28 days post-release

### Spotify Discovery Mode
**What it is:** Flag tracks as priority. Spotify boosts them in Radio, Autoplay, and Daily Mix in exchange for 30% commission on those specific streams. No upfront cost.

**Eligibility:** ~5,000-25,000 monthly listeners (Spotify says 25K but artists report access from 5K). Available via Symphonic.

**Results:** Typically 100-200% increase in streams during campaign. +50% saves, +44% playlist adds, +37% follows on average (Spotify official data).

**30% commission only applies to the additional streams you wouldn't have gotten otherwise.** Not all streams.

**When to activate:** Once you have a release with save rate 10%+. Activate for strongest track, monitor for 30 days. Turn off if no improvement after 30 days.

### Spotify Marquee (Paid, from Release 2+)
Full-screen popup inside Spotify app. €0.40-1.00 per click. Minimum €100 spend. Targets existing/lapsed listeners — not cold audiences.

**Best for:** Release week push to spike engagement and feed the algorithm. Works better for EPs/albums where there's a catalog for listeners to fall into.

**Not worth it:** Brand new artist with no followers. Spend €100 on Instagram Reels content instead.

### Spotify + ChatGPT Integration (October 2025)
Spotify is now integrated with ChatGPT. When users ask ChatGPT for music recommendations, Spotify results appear. Keyword optimization in your bio and playlist descriptions now affects AI recommendations, not just in-app search. Write all bios with this in mind.

### Post-Release Strategy If You Missed Editorial
1. Independent curator pitches — SubmitHub, Groover (but only worth it from release 2+ when you have catalog and data)
2. Build your own keyword-optimized playlist with your tracks + similar artists
3. Run small Meta ads (€50-80) pointing to Spotify if save rate >10%
4. Legitimate remix/acoustic version = new recording = new pitch opportunity
5. Strong organic save rate can still trigger Discover Weekly retroactively

## 4. Instagram

### Role in Ecosystem
Primary cold audience discovery (Reels reach non-followers). Daily engagement hub (Stories). Brand identity (Feed). Cross-platform bridge to Spotify saves and Bandcamp sales.

### Profile Optimization
- **Profile photo:** Artist photo or graphic logo. Must read clearly as small circle crop.
- **Bio:** Genre + location + what you do. Max 150 chars. Example: "Dark disco / acid / EBM from Berlin. Producer, mixer, mastering engineer."
  - Note: public Instagram posts are indexed by Google. Bio keywords affect search results.
- **Link in bio:** Smart link (Feature.fm or Linktree) pointing to current release + all platform links. Update every release.
- **Add your music:** Edit Profile > Music — visitors hear your music immediately on profile visit.
- **Pinned posts:** Best performing Reel + latest release artwork + one showing who you are.
- **Highlights:** Releases / Live-Sets / Studio / Press. Permanent and visible to new visitors.

### SEO on Instagram
- **Hashtags:** 10-15 per post. Mix genre tags (#darkdisco #acidtechno #EBM #berlinelectronic), mood tags (#underground #electronicmusic), location (#berlinmusic). Avoid massive generic tags (#music has 700M posts — invisible).
- **Caption keywords:** Captions are indexed by Google. Write genre + location naturally in captions.
- **Alt text:** Use custom alt text on images with relevant keywords.

### Reels — The Discovery Engine
Reels reach non-followers based on interest graph. This is where new followers come from.

**2026 algorithm — top signals (confirmed by Adam Mosseri, Instagram head):**
1. Completion rate (most important — especially first 3 seconds)
2. Shares via DM — single strongest algorithmic signal
3. Saves

Likes are the least important metric.

**Specs:**
- Sweet spot: 7-30 seconds (highest completion + viral potential)
- 30-90 seconds: storytelling for existing followers
- Over 90 seconds: distribution drops significantly unless retention is exceptional
- Post frequency: 3-4 Reels/week minimum, 5-7/week optimal for growth
- First 3 seconds: 50% of viewers drop off here. Hook must land immediately.

**The 60-minute rule:** Stay online for 60 minutes after posting any Reel. Respond to every comment. Instagram evaluates early engagement to decide whether to push wider. One hour of active engagement can multiply reach 5-10x.

**Audio strategy (critical 2026 update):** Instagram now actively promotes original audio from music creators and gives it algorithmic preference. Always use your own music as audio in Reels. If other users use your audio in their Reels, Instagram gives your track preferential treatment.

**Originality Score (new 2026):** Instagram detects and down-ranks recycled content.
- TikTok watermarks = auto-detected and down-ranked
- Reposted content from other platforms = reduced distribution
- Always export clean, post natively to each platform

**Instagram → Spotify direct save (2026 feature):** Fans can now save a song directly to Spotify from an Instagram Reel or Story with one tap. Always tell fans in captions: "Tap the audio and save to Spotify." This is one of the highest-conversion cross-platform actions available.

**Trial Reels:** Test a Reel on non-followers before releasing to your full audience. If non-follower performance is strong, post broadly.

**What doesn't work in 2026:**
- Begging in captions ("please support me")
- Generic hashtags
- Posting and ghosting — algorithm checks engagement within first hour
- Buying followers — 100K followers with 200 likes per post is visible as fraudulent

### Content Mix Per Release Cycle
```
40% — Release-specific (artwork, audio clips, video clips, announcements)
30% — Behind-the-scenes (studio, production process, gear, mixing)
20% — Personality/community (opinions, scene engagement, other artists)
10% — Milestones/coverage (press hits, DJ support, chart appearances)
```

### Content Formats
- **Reels:** Priority for reach. Under 30 seconds. Always original music as audio.
- **Feed posts:** Artwork, professional photos. Release announcements, high-quality visual moments.
- **Stories:** Daily during release week. Countdown stickers, polls, question boxes.
- **Instagram Live:** Release day. Artists using Live see 3x higher engagement vs regular posts.
- **Collab posts:** When a blog premieres or another artist engages — use Collab feature. Post appears on both profiles.

## 5. SoundCloud

### Role in Ecosystem
Scene and community discovery. Underground credibility. DJ promo delivery (private links). Free track distribution. Fan-powered royalties from loyal listeners.

### Profile Optimization
- **Bio:** Genre keywords + location + short description. Include: dark disco, acid, EBM, electro, techno, Berlin.
- **Links:** Connect Spotify, Instagram, Bandcamp
- **Spotlight:** Pin top 5 tracks — what new visitors see first
- **Verification:** Apply for blue tick

### Track Optimization (SEO)
Every upload:
- **Title:** "Track Name - Inch of Shadow [Dark Disco / Acid]" — include genre in brackets for discovery
- **Description:**
  - Opening sentence: mood and style of the track
  - Genre keywords naturally embedded
  - Links to Bandcamp, Spotify, Instagram
  - Collaborator credits with their SoundCloud @handles (cross-links audiences)
  - BPM if relevant
- **Tags:** Use ALL slots. Include: genre (dark disco, acid, EBM), subgenre, mood (hypnotic, melancholic, driving), location (Berlin, Germany), BPM, instruments (synthesizer, drum machine, 909, 303)
- **Genre:** Set accurately — determines which Discover algorithm surface you on

### The 48-Hour Upload Window
SoundCloud tests every new upload on ~100 genre-matched listeners (from your tags). Their engagement in the first 24-48 hours determines whether the algorithm expands distribution.

**Wrong tags at upload = wrong 100-person test group = buried track.** Tags must be accurate and specific at upload time.

**Upload Tuesday or Wednesday** to target the Friday "The Upload" playlist refresh. Uploading Friday = competing with everything else that day.

### Repost Campaigns
- Same-genre only. Cross-genre reposts signal low relevance.
- Spread over several days — not all at once.
- Pair with genuine listening activity. Pure exchange without listening = bot signal.
- Spammy repost networks actively hurt credibility.

### Audio Quality (2025 Update)
SoundCloud switched to AAC LC codec which damages transients — especially damaging for electronic music. SoundCloud acknowledged this publicly.

**Upload WAV, not MP3.** For DJ promos, use Dropbox/WeTransfer — do not rely on SoundCloud stream quality for professional use.

### SoundCloud Next Pro
Key advantage: upload private teaser → swap audio to full track on release day → all plays, likes, comments carry over. Without Next Pro, you delete the teaser and start from zero engagement.

### Fan-Based Royalties
SoundCloud pays based on each listener's actual streaming habits, not pooled. A dedicated SoundCloud following of 500 loyal listeners who loop your tracks generates more revenue per stream than equivalent casual streams on Spotify. Build loyal retention, not just plays.

## 6. Bandcamp

### Role in Ecosystem
Primary revenue source. Fan email database (owned media, no algorithm dependency). Direct artist-to-fan relationship. Scene credibility signal for labels and DJs.

### Profile Optimization
- **Bio:** 200-400 words. Genre keywords, location, influences, what makes your sound distinct. Indexed by Google — write for both in-app discovery and search.
- **Social links:** Connect all platforms
- **URL:** bandcamp.com/inchofshadow

### Tags — Most Important SEO Element on Bandcamp
Bandcamp Discover uses a recognized genre tree. To appear in Discover:
- Main genre must match Bandcamp's recognized genres exactly
- Subgenre tags must exist in the Discover tree
- **Location: use "Berlin"** — not "Neukölln" or "Mitte". Must be a city Bandcamp recognizes.
- Verify by browsing Bandcamp Discover manually. Note exact tag strings used by successful releases in your genre. Use those exact strings.

**Track descriptions:** 100-200 words per track. Include mood, production method, gear used (DJs and collectors care), story behind it.

**Pre-order setup:** Always include at least one streaming track during pre-order phase. Without it, the release doesn't appear in Bandcamp's discovery tools during the pre-order window.

### Bandcamp Daily Pitching
~1,000 pitches/week. Editors openly say they miss great music constantly. Pitch every release via their contact form. Include: release link, 1-paragraph description with context and story, why it's timely. Free, no downside.

### Fan Messaging
Direct messages to all Bandcamp followers. Highest-converting channel because they already financially supported you. Use for: release announcements, Bandcamp Friday reminders, exclusive news. Maximum 2-3 messages per year — sacred territory, don't spam.

**Bandcamp Friday communication:** Message day before + morning of. Not "support me." Specifically: "buy today, I keep 93% of the sale" or "limited edition available today only." Scarcity converts better than appeals.

### Name Your Price
Enable it. Set minimum (€3-7 per track, €7-12 per EP). Bandcamp fans regularly pay more than the minimum. A free download day (minimum €0 on Bandcamp Friday) captures email addresses and converts new visitors to fans.

### 2026 Updates
- AI music explicitly banned. Human producers are actively positioned as authentic.
- Stripe payment transition underway. Update payout settings when contacted.
- Publishing rights fields added — fill them out for royalty attribution.

### YouTube Shorts — Discovery Engine
- Tests with small viewer batches; strong performance → surfaces to larger audiences, sometimes weeks later with delayed viral
- Shorts can go viral on brand new channels without subscriber gating
- Short hooks (roughly 15-35s) work well; no official ideal length, Shorts can run up to 3 minutes and upload at max 1080p
- Open with strongest moment (hook, drop, most hypnotic section)
- Link the full track with the Shorts related video link (needs advanced features); a spoken CTA is the fallback

### YouTube Premiere
Use for all major releases. Countdown starts 2 minutes before, optional trailer, live chat during debut. **Max 1080p**: our 4K renders need a 1080p export. YouTube for Artists: go live at least 15 minutes before and use Live Redirect into the Premiere.

### YouTube → Spotify Synergy
YouTube is top-of-funnel discovery. Every video must actively drive to Spotify:
- Spotify link pinned in comments

## 8. Beatport & Traxsource

### Role in Ecosystem
DJ credibility. Chart appearances = signal to labels, managers, and promoters that you belong in the scene. In underground electronic, a Beatport chart appearance is worth more than 10,000 Spotify streams as an industry signal.

### Beatport Profile
Update via Beatport's dedicated form (not self-serve). Submit:
- High-resolution profile + banner photos
- Keyword-rich bio: genre + influences + sound
- Social media links
- Website link

Bio keywords: use exact genre terms used on Beatport (dark disco, EBM, electro, acid house, techno).

### Lead Times — Official from Beatport Label Support
- **3 weeks minimum** to deliver music before release
- **2 weeks** is the editorial feature assignment cutoff — **anything delivered after 2 weeks before release is automatically ineligible for editorial features, banners, and store placement. Hard cutoff, no exceptions.**
- **4 weeks (28 days)** is the maximum pre-order window

### Pre-Order — The Chart Mechanism
Without pre-orders: you launch from 0 sales on release day.

With pre-orders: every sale in the 28 days before release is spread across your first week of charting. 50 copies pre-sold = you launch with 50 units of momentum. This is how unknown tracks appear in Top 100 on release day.

Pre-order links under SoundCloud snippets = major conversion point used by labels routinely.

**If you miss the 28-day pre-order setup:** cannot be added retroactively. Launch from zero. No recovery.

### Beatport Pitch — What to Include
Per Beatport's own documentation:
- 3-5 DJ names supporting the track (any level)
- Any footage of the track being played
- Your marketing plan and social numbers
- Frame: "if you feature this, we will promote it together"

**Never pay money to agencies claiming guaranteed Beatport Top 100 placement.** Beatport calls these out as scams. Charts reflect real sales only.

### Chart Mechanics
- Beatport Top 100 updates daily based on last 7 days of sales
- DJs buy primarily on Mondays (exclusive releases) and Fridays (standard release day)
- Friday release dates are optimal

### DJ Chart Strategy
Create a Beatport artist chart including your own tracks + 9 tracks you genuinely support. Share on all socials. Submit for editorial consideration via distributor. Other artists on your chart may share it — cross-promotion built in.

### Beatport Hype
Section for emerging artists. Hype levels the playing field. Ask Symphonic if they participate. Hype labels can appear alongside established artists.

### 2026 Beatport Updates
- LabelRadar integration expanded — DJs discover promos directly in rekordbox, Engine DJ, and Traktor software. Being properly genre-tagged matters more because DJs find you inside their workflow.
- More frequent genre playlist updates throughout 2026.
- Beatport Next 2027 applications open November 2026.

## 13. Singles vs EP Strategy

### Singles Are the Better Strategy (Data-Backed)

For independent artists at catalog-building stage, consistent single releases outperform EP drops:

- Every single = a new Release Radar event for your followers. Two singles = two events. One EP = one event.
- Every single = a new Spotify editorial pitch opportunity. One focus track per release. Singles maximize pitch count per year.
- Spotify's algorithm rewards consistent release cadence. Optimal for independent artists: every 4-6 weeks. Only sustainable with singles.
- Each release compounds the previous — second single reaches a larger audience because the first grew it.

### The Waterfall Strategy
1. Release singles 4-6 weeks apart with connected visual identity
2. Each single is its own complete release — own Spotify pitch, own Beatport pre-order, own campaign
3. After 3 singles in the same visual/sonic world, bundle as an EP on Bandcamp and via Symphonic
4. This gives you: 3 separate algorithmic events + 3 editorial pitches + a catalog artifact for press and DJ promo

### Visual Identity for Series Releases
Same artwork file across two releases is fine — no platform algorithmically penalizes it. Spotify, Beatport, SoundCloud, Bandcamp treat it as neutral or positive for series identification. Check Symphonic's policy on duplicate artwork before submitting.

Better approach (EsDeeKid model): same visual DNA, distinct images. Same palette, same character/motif, same treatment — different compositions. Reads as a series from the discography grid without being identical files.

## 14. Bandcamp Friday 2026

### Confirmed 2026 Dates
February 6 · March 6 · May 1 · August 7 · September 4 · October 2 · November 6 · December 4

Eight dates — more than any previous year. Bandcamp waives revenue share. Artists keep ~93% after payment processing (Stripe).

### When to Plan Around It
Worth aligning to if a Bandcamp Friday falls within 2 weeks of your planned release — zero cost to align the Bandcamp drop to that date. Not worth restructuring your whole campaign (messing up Spotify editorial pitch window or distributor timeline) if the nearest date is 6+ weeks away.

The real value is not the extra revenue percentage (small at early career stage) — it's the communication excuse. Bandcamp Friday gives a specific, legitimate reason to message all followers without it feeling like spam.

### Communication That Converts
Message followers the day before and morning of. Not "please support me." Specifically:
- "Buy today, I keep 93% of the sale"
- "Limited edition / exclusive bonus available today only"
- Scarcity and specificity convert better than general support appeals

From tracking data on 200+ artists: the difference between artists making €47 and €2,300 on the same Bandcamp Friday had nothing to do with following size — it was communication strategy.

## 15. 2026 Platform Changes — What's New
