# Ambertone Studio — Shot List / Angle Bank

Reusable reference for filming IG content at the studio. Rotate the primary angle each release so it stays fresh.

## Ground rules
- **Mixing/mastering studio** — content focuses on the mix desk / process, not playing instruments.
- **The drum kit is NOT permanent** (temporary) — don't build shots around it or imply tracking.
- **The ceiling LED is COLOR-CHANGEABLE** — the biggest lever. Match it to the release palette.

## Hero visual elements
- **Color-changeable ceiling glow** behind the pixelated diffuser cubes — signature light (usually red).
- **Orange retro globe pendant lamp** — signature prop; centers every wide shot.
- **UAD Apollo Twin + white custom (Bespeco) desk** — hero gear, great for close-ups.
- **Red velvet curtains + daylight Altbau window** — consistent backlight, warm/cool tension.
- **Chart award trophy** (Offizielle Deutsche Charts / "#1") on the shelf — quiet credibility prop.
- **Himalayan salt lamp** — warm orange glow; use as foreground bokeh.
- **Vintage layered rugs, plants, green velvet chair, wood-slat wall, green acoustic panel** — texture/warmth.

## Angle bank
1. **Doorway establishing** / slow push-in toward the desk — best reel opener.
2. **POV / over-the-shoulder at the desk** (Apollo Twin + monitors + window behind) — the hero mixing frame.
3. **Apollo Twin knob close-up** — tactile gear hook.
4. **Hands on the console / faders** — process.
5. **Face + orange lamp / colored ceiling glow** (sunglasses = signature) — portrait/hook.
6. **Ceiling tilt** up to the glow + diffuser cubes — abstract cutaway.
7. **Award trophy** featured subtly — credibility.
8. **Shoot past the salt lamp** — warm foreground bokeh, depth.
9. **Window backlight** through the red curtains — silhouette / flare.
10. **Texture cutaways** — rug patterns, plants, green chair, mic.

## Keep it fresh (per release)
- **Change the LED color** to match the release palette.
- **Pick a different primary angle** each release (doorway → POV → ceiling → face, rotate).
- **Day vs night:** daylight = warm/human; night, lights off = colored-glow moody.

- Lean **night / moody**; primary angles: **POV desk + Apollo close-up + blue ceiling tilt.**
- Warm room vs cold cover = intentional tension (process warm, product cold).
