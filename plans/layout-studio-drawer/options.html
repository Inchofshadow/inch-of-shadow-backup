The shared tag list

Today each library tags in its own way: Archive has topics and a few tags (90s-noir on R-022), Fonts has free words, Effects has families only, Imagine has none.

T1One fixed list

One file of about 30 tags that every library uses. I tag what is there now from that list. A new tag is added on purpose and shows up for all four at once.
