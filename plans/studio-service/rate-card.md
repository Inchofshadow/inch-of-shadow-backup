What "alt" and "instrumental" are (Amir asked 11-12):
- **Alternative version mix**: a second version of a song you already mixed, e.g. a radio edit (shorter, clean words), an extended club mix, or a TV/sync version. Same mix settings, so it costs less than a new mix.
- **Instrumental version mix**: the same mix with the vocals muted, often asked for by labels, sync agencies and DJs.
- Both are optional rows. Keep, drop, or merge them into one row "Extra version (edit / instrumental)".
