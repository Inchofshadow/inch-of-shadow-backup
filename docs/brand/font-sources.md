# Inch of Shadow - Where to get each font (2026-09-21)

One link per face in `font-library.md`, so nobody searches twice. The library says WHAT each
font is and where Amir saw it. This file says where to buy or download it, what it costs,
and whether a trial exists. Checked 2026-09-21. Prices are USD unless marked.

## Read this before buying anything

**A font in Canva is not a font you own.** The fourteen faces Canva has (`canva-setup.md`)
can be used inside a Canva design at no cost, and that is the whole of it. Canva gives you
no file. So the moment a face has to appear in

- a HyperFrames video (the composition loads a real file through `frame_tokens.py`),
- anything `image_generator.py` or `print_looks.py` draws,
- a cover going to Symphonic,

it needs a licence and a file on disk, Canva or no Canva.

**Always read the logo clause before a face becomes the wordmark.** A desktop licence
usually covers a cover and a video. Using the letters AS the logo is often a separate,
dearer licence.

**Trial files are for looking at on screen. Nothing made with them goes out.**

## Things that turned out not to exist

Worth knowing before anyone spends an hour looking.

- **Steile Futura** has no current release under its own name. Buy **URW Topic**.
- **Primer** is sold as **Century 751**.
- **Melior Bold Condensed** cannot be licensed at all.
- **Antikva Margaret** has no proper digital release. The free downloads are unlicensed rips
  of a 1992 Image Club file. For the Flock of Seagulls look exactly, expect to redraw.
- **Corvinus Skyline**: the MyFonts listing is dead and FontHaus is down. Only an
  unconfirmed YouWorkForThem page remains.
- **Thor** was never licensed digitally. Every version is a redraw.
- **Oxford Swash** is real but has no digital release. See the correction below.

## Oxford Swash, the Memory of Megan title (corrected 2026-09-21, Amir asked)

An earlier version of this file said "Oxford Italic Swash" was not a real typeface. **That
was wrong.** It came from a search that found a different Oxford, Christine Lord's linked
lowercase of 1969. The Fonts In Use typeface page settles it:

**Oxford**, also called **Oxford Italic**, is a standalone italic released by
**Lettergraphics**, by 1968, designer unknown, and it derives from **Volta Italic**.
**Oxford Swash** is the variant carrying swash alternates and a single-storey `g`, and that
is what the cover uses. The page's contributor adds that the `f` on the cover is a
modification, because none of the face's own alternates has a ball terminal at the bottom
of the f.

No digital release of Oxford was found. The one real lead is **Volta** (Bauer), the face it
comes from. The page also says "Pushkin may be the same or similar design", but ParaType's
Pushkin is unrelated, drawn from the poet's handwriting, so that lead is not confirmed.

Reference: https://fontsinuse.com/typefaces/236470/oxford-italic

The lesson is the same one as Cooper BT: a name search is not an identification. Read the
Fonts In Use typeface page before declaring that something does not exist.

## The Bookmania answer, which closes an open question

`canva-setup.md` records that Canva's Bookmania is upright only, so the Real Estate "Days"
logo cannot be made there. **Mark Simonson's own Bookmania carries 47 swash glyphs in the
italic**, and it is the modern release of exactly the Sixties Bookman that was everywhere in
1970s film type. So the look is buyable for $237.49; Canva's version is a stripped subset.

## Cheapest routes, if money is the question

- **Creative Cloud**, if a subscription is ever in play, covers **Univers Next** (63 styles,
  against $429.90), **Gill Sans Nova** (against about $506.99), **Clarendon Text** and
  **Dutch Mediaeval**. That is the single biggest saving on this page.
- **Fontstand** rents by the month and gives 3 hours free on the desktop: Harbour, BVH BLine,
  and it carries Alias and Dinamo, so Ano and ABC Favorit can probably be trialled there too.
- **Letterhead Fonts** sells each title at $15 to $29, 10% off from four up. The whole bundle
  is already on disk for looking at.
- The **cheapest face Amir has actually admired on his own name** is Albertus Nova at $104.99
  for five weights.
