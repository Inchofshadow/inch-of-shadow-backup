# R-001 · Reel · "Fonts Your Favorite Artists Use: Bob Dylan" (@andreyazizov)

- **Source:** https://www.instagram.com/p/DeQEZoJOJRR/ (2026-10-08, 15s, ~13k likes). A capability test; Amir does not know the creator.
- **What it is:** talking-head intro (sunglasses, warm room, 3-line title, "Part 1"), then one slide per album: font name above the cover. Helvetica Black (Highway 61 Revisited), Times New Roman Bold (Bringing It All Back Home), Gothic Antique / Franklin Gothic (The Times They Are a-Changin'), Franklin Gothic (Freewheelin'), Baby Teeth (Milton Glaser poster). Font names are the creator's claims, not verified.
- **Technique:**
  - Each font name is set in its own font, in the cover's own colour. The label is the specimen.
  - One idea per slide, cut every 2-3s, no voice after the intro.
  - Background colour on each slide is taken from the cover, so the type and the art read as one piece.
  - Series framing ("Part 1") plus a caption question ("What artist should I do next?") gets comments without spending screen time on a CTA.
- **Tip:** a font test is fastest when the name sits on the real art. Judge type on the image it will live on, never on a blank page.
