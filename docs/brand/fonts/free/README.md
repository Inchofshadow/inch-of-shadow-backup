covers, videos, anything the tools draw. All four are also uploaded to the Canva Brand Kit

**Viking may NOT be modified.** Its licence forbids altering the letterforms, and forbids
selling or publishing the font file. Use it as drawn. It is the practical stand-in for Thor,
the uncial on The Cure's Lovesong sleeve, which was never licensed digitally.

The static Jost and Mohave weights came from the Google Fonts CSS API; the variable files
came from github.com/google/fonts. Marcellus, the other free face, sits one level up
because it is the brand fallback.

**Switzer may not be passed on.** The ITF licence allows commercial work and logos, but the
font file may not be given to anyone else (designers, printers get the finished files, not the font)
or offered to others through a website or design tool.
