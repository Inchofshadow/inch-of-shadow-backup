# IG Clip Glue — standard workflow (CapCut free, Mac)

**Purpose:** marry a clean track bounce to silent/any studio video, export a loop-ready
vertical clip. The room is acoustically tuned for the mixing position only, so we NEVER use
the phone's in-camera audio. Picture and sound are recorded separately and married here.

## One-time prep (per release)
- Bounce a **clip-ready audio export** from the session: one or two strong 15–30s sections
  (a clear hook / groove that loops). WAV or 320 MP3. Keep them in a per-release folder.
- The single most important rule of the whole system: **the audio is the real track file,
  never the phone mic.**

## Build the template ONCE (then duplicate it every time)
CapCut free has no "save as template" button, but it lets you **duplicate a draft**. So:
1. New project, set canvas to **9:16 (1080×1920)**.
2. Drop in a placeholder video + a placeholder audio so the structure exists.
3. Pre-set your export defaults (1080p, 30fps, High).
4. Name it `IOS — CLIP TEMPLATE`. From now on, **right-click → Duplicate** this draft for
   every new clip. That duplicate IS your template.

## Per-clip steps (repeatable, ~5 min)
1. Duplicate the template draft, rename it (e.g. `deceiver_overhead_v1`).
2. Replace the placeholder **video** with your footage.
3. **Kill the original audio:** select the video clip → set its volume to 0 (or detach
   audio and delete). This removes the bad room/phone sound.
4. Replace the placeholder **audio** with your clean track export.
5. **Trim the video to a musical phrase** so it ends on a beat. For a seamless loop, make
   the first and last frames look similar (same pose / same spot).
6. (Reels only) apply the grade — see below. (Feed/story can skip it.)
7. One text overlay max if needed. Keep it clean (no clickbait, no "POV:", single dash).
8. Export 1080p / 30fps / High. Post.

## Dark grade recipe (Reels for dark releases like The Deceiver)
In CapCut → **Adjust**:
- Brightness: slightly down
- Contrast: up
- Highlights: down · Shadows: down (push true blacks)
- Saturation: down ~10–20%
- Temperature: slightly cool
- Add **Grain** effect at low intensity (texture, "felt not seen") + subtle vignette
- Keep ONE warm pop in frame (salt lamp / streetlight) as the only color — don't desaturate
  it away.
This was the bleach-bypass / high-contrast EBM look of the electronic era (old file: `plans/ig-content-craft-reference.md`, retired). Current rule, `docs/brand/reel-craft.md` section 2: match the grade to the mood of the piece; the brand is never only dark.
For warm / daylight / disco posts: skip the dark grade, keep it bright and natural.

## Canva vs CapCut
- **CapCut** = primary glue: beat-syncing, trimming to the music, grading, loops.
- **Canva** = design-forward posts: text-heavy covers, carousels, brand-kit layouts, quick
  resizes. Canva can also replace audio, but CapCut is better when timing to the music matters.

## Link reality (important for "new track is out" posts)
- **Reels & feed posts can NOT have a clickable link.** Overlay says "link in bio", and you
  set the bio link to the release smart link on release day.
- **Stories CAN have a clickable link** via the **link sticker** — point straight to the
  smart link there. Best practice on release day: Reel for reach (link in bio) **plus** a
  Story with the link sticker for the actual click.
