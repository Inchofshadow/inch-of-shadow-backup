03 What can actually be pitched

Four tiers, in descending order of how much you should trust the answer. The bottom tier is physics, not a limitation of the tool.

Reliable note

A real note plus cents. This is what you can tune a track around.

Kicks · toms · bass one-shots · cowbell · clave · conga · bongo · single held vocal or synth stabs
Root guess only

More than one note is sounding, so you get the strongest one. Often the chord root, sometimes wrong. Labelled as root, never as the note.

Pads · chords · stacked stabs
Key, not note

The pitch moves through the file, so a single note is meaningless. Needs key detection, which is a different algorithm from what the tool does today.

Melodic loops · vocal phrases · moving basslines
No pitch

These have no fundamental to find. Nothing to report, and that is correct rather than missing data.

Snares · claps · hats · cymbals · risers · impacts · noise FX

Bass is the easiest of all

Bass one-shots detect more cleanly than kicks do. The catch is that the tool has no bass rule at all right now, so bass files fall through as untyped and never get analysed. Adding a BS type is on the fix list.

04 The confidence score

Your 80% rule, made concrete. Every detected note carries a score, and below the threshold the tool prints nothing at all instead of guessing. A blank is honest. A wrong note sends you chasing a key that was never there.

Three things get measured

  1. Periodicity. How strongly the waveform repeats itself. A kick tail repeats cleanly, a snare never repeats at all. This alone separates most tonal hits from noise.
  2. Stability. The tail gets chopped into slices and each slice is measured separately. If they all agree within about 20 cents, the pitch is solid. A pitch sweep or a moving vocal makes the slices disagree.
  3. Tonality. Whether the spectrum has sharp peaks or is flat. Flat means noise, peaked means a real fundamental with harmonics above it.

The three combine into one score out of 100. Anything at or above the line gets a note in its filename. Anything below gets left blank and stays blank.

The threshold is adjustable with --min-confidence. Lower it to 60 and you will see notes on pads and detuned kicks, some right and some wrong. Raise it to 90 and only the certainties get through. The report always keeps the score, so a blank can be investigated rather than being a dead end.

05 Naming

MACHINE source box TYPE two-letter sound code PITCH only when confident NN counter
RX5_BD_G0_01.wav kick, note found SR16_SD_03.wav snare, no note by design DMX_TOM_C1_02.wav tom, note found LM2_CH_07.wav closed hat, no note

Type codes: BD SD RS CP CH OH RD CR CY LT MT HT TM CB CL CG BG SH TB MA PC FX, plus BS for bass once added. Octave numbers follow Ableton, where C3 is 60, so 50 Hz reads as G0 and matches what Live shows you. Tuner convention is available with a flag.

06 Why your projects cannot break

The guarantee

The tool copies. It never renames or moves an original. Your projects point at the old files, which stay exactly where they are under their old names, so there is nothing to relink.

  1. Never use --in-place. It is the only flag that touches originals.
  2. Ableton finds missing samples by filename. Rename an original and the automatic search fails, leaving you to locate every sample by hand.
  3. Before any bulk work, run File → Collect All and Save on active projects. That copies samples into each project folder and makes those projects immune to anything done afterwards.
  4. SAMPLES MAC stays the raw archive. The renamed copies become the working library.

One thing to watch

SAMPLES MAC is already in Ableton's Places. Once the renamed copies live inside it, every sample turns up twice in browser search, once raw and once renamed. Point Places at SAMPLES MAC/Drum Machine Tune instead of the whole folder, and the browser shows only the clean library while the raw archive stays on disk.
