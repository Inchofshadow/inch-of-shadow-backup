Build SC Playlist Curator Discovery into Scene Intelligence (Tool 1).

**Why:** Getting tracks added to curated SC playlists (e.g. "Dark Disco 2026", "Berlin Techno Underground") exposes music to targeted audiences. This is one of the strongest organic growth levers on SC.

**How to apply:** Use the SC API to find playlists matching Inch of Shadow's genres (dark disco, acid techno, EBM, electro, darkwave), identify who runs them, and add them to the enriched_contacts.json for outreach via Promotion Engine. Needs investigation into what the SC API actually exposes for playlist search.
